## What was checked while writing these docs (2026-10-08)

Everything in [reference/](../reference) was written by **reading the source**
(`webserver.cpp`, `signatures.cpp`, `file_log.cpp`, `memory.cpp`, `capture.cpp`,
`resources/webserver/index.html`) and checked against one real hit line from
gama's `hits.jsonl`. **Nothing was built or run**: no DOSBox build, no gtest
run, no live session. If a page says a behaviour exists, the code says so; if
it says what a value *means*, that is marked as a guess.

`mdl` is not installed, so the markdown lint did not run.

## How we work here

- Follow [`.claude/rules/`](../../../.claude/rules): C++ style, commit prefixes
  (`docs:`, `build:`, `style:`, `website:`; **not** `feat:` or `fix:`), every commit
  must compile (`scripts/tools/compile-commits.sh`), British spelling in docs.
- **No `Co-Authored-By` lines** in this repo's commits.
- Keep changes inside `src/webserver/` where you can. That is what keeps
  rebasing on upstream cheap.
- A memory dump, a screenshot or a hit log holds a game's own code and data.
  Don't commit them. Put them in an Evi vault.
